# T3: Film tool: Catalog Metadata and Spoiler List

[#3](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/3) · PR [#24](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/24) · merged 2026-10-29

T3 gave the agents a Film's **Catalog Metadata** and **Spoiler List** through two read-only MCP servers. The list reaches only the Checker (ADR 0007).

## Spec

- **Done when:** the agents can look up title, synopsis, genre, cast, language and the Spoiler List for a sample Film.
- **Decisions:**
  - **The file:** one `films/<film>/film.toml` per Film (`[catalog]` and `[[spoilers]]`), read with stdlib `tomllib`, so there's no new dependency.
  - **Catalog fields:** title, synopsis, genre, language, runtime_minutes (from the glossary, though the ticket omits it), cast as `{character, name?}` with no guessed actors, and an optional trailer link.
  - **Spoilers:** each is `{id, text, why?}`.
  - **Visibility:** the Spoiler List is a separate server for the Checker only. The Watcher and Copywriter get the catalog.
  - **Read-only:** no write tool, text over 2,000 characters refused, and every field marked as data, not instructions.
  - **Git:** every real Film's folder is gitignored, and only the sample `agent-327` is tracked.
  - **The sample:** published facts only (Agent 327, Boris Kloris, no actor names) and one spoiler, `ending-capture`, grounded in the T2 transcript. `barber-is-kloris` was left out because it's unconfirmed.

## Plan

The steps were: sample file and gitignore → strict loader → servers → CLI → README. Changes from the plan:
- **Two servers, not one tool switch.** Any client that connects to a server sees all its tools.
- **Errors name the Film, never the local path**, since T4 passes tool errors to a model.

## Tests

- **The loader** refuses missing fields, wrong types, unknown keys (a typo must not silently drop a field), duplicate spoiler ids, overlong text and huge files.
- **The servers** each offer exactly one tool, and the catalog response never contains the spoiler's words.
- **Git:** a real Film's files, backups included, can't reach git.

310 tests passed at merge.
