# T1: Project skeleton and Film Budget meter

[#1](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/1) · PR [#22](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/22) · merged 2026-10-29

T1 gave the project its application package and the **Film Budget** meter that every paid model call goes through, with a **Run Log** of what each Run spent (ADR 0005).

## Spec

- **Done when:** a dummy run with a tiny budget stops with a clear "Film Budget reached" message, spend is written to the run log, and CI stays green with the new tests.
- **Decisions:**
  - The default Film Budget is $2.00 per Run, overridden by `FILM_BUDGET_USD` or `--budget`.
  - No runtime dependency: the meter takes plain token counts and a model id, and the Anthropic SDK waits for T4.
  - The hard stop happens **before** each call: reserve the worst case, refuse if it could pass the budget, charge the actual cost after.
  - A model missing from the price table is refused, never guessed.
  - Layout: `src/trailer_to_campaign/`, a `t2c` command, Run Logs in `runs/<film>/<UTC timestamp>/run.jsonl`.
  - Glossary, settled during review: the Film Budget caps **one Run**. Rework after a rejected draft stays in the same Run, and a Run ends at the Social Posts Approval.

## Plan

Tests came first for each module: `pricing` → `run_log` → `budget` → `config` → `cli`. Prices are from the live pricing page on 2026-10-29. Packaging uses the `uv_build` backend, approved in the plan.

## Tests

The meter tests are the core:
- Spend never exceeds the limit over 500 random calls.
- A call is refused before it runs, and a call that fits exactly is allowed.
- An error, or a missing `record()`, charges the worst case.
- Nested open calls can't overspend, and unknown models are refused without a charge.

152 tests passed at merge.

## Evidence

- `t2c dummy-run --budget 0.001` → `Film Budget reached: spent $0.000000 of $0.001 (the next call could cost up to $0.036000)`, exit 3.
- With `--budget 0.05`: one call at $0.018, then the stop.
- With the default $2.00: three calls completed for $0.054.

## Close the loop

- **Glossary:** **Run** and **Run Log** added. **Film Budget** now caps one Run.

- **Lesson:** "A hard stop is only as hard as what it's told."
