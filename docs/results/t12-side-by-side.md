## Read these numbers with this in mind

This trial did not fully follow `docs/side-by-side.md`:

- **The two sides did not start together.** Marketer A did the old way on the afternoon of 2026-11-03. Marketer B's Run started at 23:47 that night. Times on this page are UTC+7; the Run's name below is in UTC.
- **A's 40 minutes is from memory.** It wasn't timed with a stopwatch and written down on stopping, so Time Saved is an estimate, not a measurement. B's 5 minutes was timed with a stopwatch, paused while the agents ran.
- **A isn't a typical old-way marketer.** A built the tool, made the Film, and wrote its facts and Spoiler List. The protocol keeps whoever set up the tool off the tool's side, because knowing the system would make them faster, so A took the old way. Knowing the Film so well may make the old way look faster than it is. If A doesn't normally write launch posts, it may look slower. A also has a stake in the result, and the first record of the 40 minutes is the command that also holds B's 5. So the 88% could be too high or too low.
- **What A used:** the trailer, A's own writing and ChatGPT for the Vietnamese.
- **One Film, one Run, and an easy one.** This shows the tool working on a real launch. It doesn't show an average. The trailer has no speech to transcribe and no lines to misquote, and it lasts only 40 seconds, so the cost and Approval Rate may not hold for a dialogue-led trailer.

A's work came before B's Run, and the Key Moments from the earlier Watcher test were kept from A, so A hadn't seen the tool's output for this Film while writing. A's posts existed before B's Run, and B confirmed not seeing them before finishing.
