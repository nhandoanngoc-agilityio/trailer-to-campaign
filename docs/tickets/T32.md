# T32: `t2c --version` prints the package version

[#86](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/86) · PR [#<pr>](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/<pr>) · in progress

`t2c --version` prints `trailer-to-campaign <version>`, read from the installed package's metadata, and exits 0 before any settings load, so it needs no API key, films folder or valid environment.

## Spec

What the ticket asked for, and what Analyze settled.

- **Done when:** `t2c --version` prints `trailer-to-campaign <version>` from the package metadata and exits 0.
- **Decisions:**
  - Flag spelling: `--version` only, no short `-V`, because the ticket names only `--version`. `-v` stays `--verbose`.
  - Output stream: stdout (argparse's `version` action on 3.11+, and the Unix convention).
  - Package not installed: print `trailer-to-campaign unknown` and exit 0, rather than make every `t2c` command fail.
  - Name: the distribution name `trailer-to-campaign` is both looked up and printed, from one `DISTRIBUTION` constant.
  - Top-level only: `t2c run --version` stays a usage error.
  - Tests in-process only; the console-script wiring is already covered by `test_t2c_is_installed_as_a_command`.
  - No `__version__` in `__init__.py`; `pyproject.toml` unchanged.
  - Docs: one line in the `cli.py` docstring and one in the README command block.

## Tests

Five new tests in `tests/test_cli.py`, all through `main([...])` in-process:

- `test_version_prints_the_package_version_and_exits_0`: exact stdout against `importlib.metadata.version("trailer-to-campaign")`, with `env={}`.
- `test_version_follows_the_package_metadata`: a patched lookup returning `9.9.9` is what's printed, so no version is written into the code.
- `test_version_works_with_bad_settings_in_the_environment`: bad `FILM_BUDGET_USD` and `T2C_WATCHER` don't stop it.
- `test_version_without_installed_metadata_says_unknown`: `PackageNotFoundError` gives `trailer-to-campaign unknown`, exit 0, and other commands still parse.
- `test_the_help_lists_the_version_flag`: `--version` is in `t2c --help`.
