# T2: Footage tool: frames and transcript

[#2](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/2) · PR [#23](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/23) · merged 2026-10-29

T2 gave the Watcher its eyes and ears: an MCP server that turns an official trailer into **Frames** with timestamps and a timestamped **Transcript** (ADR 0002, ADR 0003), and refuses screeners (ADR 0005).

## Spec

- **Done when:** for one real trailer it returns frames with timestamps and a transcript, and rejects anything marked as a screener.
- **Decisions:**
  - Transcription runs locally with faster-whisper (`small`, overridden by `T2C_WHISPER_MODEL`). It spends nothing against the Film Budget.
  - Inputs:
    - a local file in `films/<film>/source/`, or
    - an https link on youtube.com, youtu.be or vimeo.com, fetched by yt-dlp limited to its YouTube and Vimeo single-video extractors.
  - Limits: 10 minutes and 500 MB.
  - Only an explicit `kind="trailer"` is accepted. A name or title containing "screener" is refused before any download or ffmpeg.
  - Two tools: `watch_footage` returns the timeline, and `get_frame` returns one image, so the Watcher pays only for the frames it needs.
  - Sampling: a frame every 3 s plus scene changes (0.4 threshold), capped at 120, at most 768 px.
  - Cache: `films/<film>/frames/<sha12>/`.
  - Dependencies `mcp`, `faster-whisper` and `yt-dlp` were approved, and CI installs ffmpeg.

## Plan

Tests came first for each module: `sources` → `frames` (real ffmpeg on a generated clip) → `transcript` → server → README. Changes from the plan:
- `get_frame` also takes a `footage_id`, since a Film can have several trailers.
- PyAV is held below 19, because faster-whisper 1.2.1 breaks on it.

## Tests

- **Links:** the allowlist refuses IPs, localhost, user info, ports and look-alike hosts.
- **Screeners:** every non-`"trailer"` kind and every screener name or title is refused, with spies showing zero ffmpeg calls, downloads or transcriptions.
- **Frames:** real ffmpeg finds the planted cut at 6.0 s.
- **Transcripts:** a slow, local-only test checks real Whisper on generated speech.

247 tests passed at merge.
