# T31: Apply Claude Code's best practices to this repo's setup

[#84](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/84) · PR [#<pr>](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/<pr>) · in progress

Brings the repo's Claude Code setup in line with the best-practices guide. A `Stop` hook now enforces lint before Claude finishes. The ticket loop becomes a skill, and the rules that matter in only one folder load only there. `CLAUDE.md` gets shorter and loses nothing.

## Spec

What the ticket asked for, and what Analyze settled.

- **Done when:**
  1. A `Stop` hook runs `ruff check` and `ruff format --check` on the `.py` files that changed in the working tree (tracked changes and untracked files). It exits 2, with ruff's output on stderr, when either fails, and 0 when they pass or no `.py` file changed. Tests cover both sides.
     _Check:_ `tests/test_hooks.py` cases on a temporary repo: a bad file exits 2 and its stderr names the file, a clean file exits 0, no change exits 0, an untracked bad file exits 2, a deleted file exits 0.
  2. The Stop hook has a time limit, never changes a file, uses only the standard library and runs on Python 3.9, tested like the other hooks. A test pins what it does when ruff is missing or times out.
     _Check:_ the tests run under `hook_python()` (3.9). The file's bytes are unchanged after a failing run. Cases cover a missing ruff and a stubbed ruff that sleeps past the limit.
  3. The ticket loop moves out of `CLAUDE.md` into a skill Claude loads on its own when it works a ticket. `CLAUDE.md` keeps one pointer to it, the 🧑 gates, and every "Never do" line. `ship-ticket`, `review-checklist`, `docs/workflow.md` and `prompt_changed.py` point to the new place.
     _Check:_ a test that every "Never do" line on `main` is still in `CLAUDE.md`, plus a test that every reference to a `CLAUDE.md` section matches a heading that exists.
  4. The Layout section keeps only what Claude can't find by reading the repo.
     _Check:_ review the diff. Every removed line is listed in this record with where it went or why it was dropped.
  5. `.claude/rules/` holds path-scoped rules for footage, prompts and the Film Budget.
     _Check:_ a test that every rule file has `paths:` frontmatter and each pattern matches at least one tracked file.
  6. `.worktreeinclude` lists `.env`, `.gitignore` ignores `CLAUDE.local.md`, and `format_on_edit.py` uses the project's own ruff.
     _Check:_ `git check-ignore CLAUDE.local.md`. A hook test shows `format_on_edit.py` calls the project's ruff and never `uvx`.
  7. `.claude/agents/reviewer.md` is read-only (`tools: Read, Grep, Glob`).
     _Check:_ a test that parses its frontmatter, with no Edit, Write or Bash.
  8. `CLAUDE.md` is shorter and loses nothing.
     _Check:_ `wc -l` before and after, plus the line-by-line table under **Plan**.
- **Decisions:**
  - Lint only, not the tests, in the Stop hook: the full suite takes about 92s (measured on `main`, 1624 tests), too slow for every time Claude finishes a turn. Tests stay a written step in Verify, and CI enforces them.
  - Only the changed files are linted, not the whole repo, so stray files outside the change can't hold a session hostage. CI still lints everything.
  - Branch protection on `main` is out of scope: it's a GitHub setting, not repo content, and the human decides it.
  - Open: whether the Stop hook passes or blocks when ruff is missing or times out. Put to the human in Plan.
