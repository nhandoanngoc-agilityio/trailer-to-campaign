# T24: The guardrail hooks work on the machine's python3

[#68](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/68) · PR [#<pr>](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/<pr>) · open

The Bash guardrail hook blocks again. It had been crashing on the Mac's `python3` since 2026-10-30, and a crash let every command through. Now it runs on Python 3.9, and a crash blocks the command.

## Spec

`.claude/settings.json` runs the hooks with `python3`, which is `/usr/bin/python3`, 3.9.6, on this Mac. `block_forbidden.py` called `zip(..., strict=True)`, which needs 3.10, so every Bash command raised `TypeError` and exited 1. Only exit 2 blocks. The tests used the project's Python, so they stayed green.

- **Done when:**
  - Under `/usr/bin/python3` (3.9.6), `git push --force origin main` and `git push origin main` exit 2, and `git status` exits 0.
  - `tests/test_hooks.py` runs every hook with the `python3` the settings would find, not the project's virtualenv, and goes red on `main`'s code.
  - CI runs the hook tests on Python 3.9 as well, so a runner with a newer `python3` can't hide this.
  - If `block_forbidden.py` crashes while judging a command, it exits 2 and says the command wasn't checked. Input that isn't JSON still exits 0.
  - Ruff judges `.claude/hooks/` as Python 3.9, so it can't ask for 3.10-only code there again.
- **Decisions:**
  - **Keep `python3` in the settings:** the hooks stay on the standard library, so they run before `uv sync` and in any clone. They now promise 3.9, the oldest `python3` a Mac ships.
  - **A crash blocks every Bash command until it's fixed:** that's loud, but silent is what hid this for five days. Edits still work, so the hook can be repaired. Input that isn't JSON still passes, as before, so a change in what Claude Code sends can't lock a session out.
  - **Not fixed here:** a machine with no `python3` at all, or one older than 3.9, still fails open, because the hook never starts.

## Tests

On `main`'s code, 93 of the 101 hook tests failed on this Mac's `python3`. All 101 pass now. Ruff's B905 is the likely way the 3.10 call got in: it asks for `strict=` when the target is 3.10 or newer, and the project's target is 3.11. The Ruff test goes red without the per-file target.
