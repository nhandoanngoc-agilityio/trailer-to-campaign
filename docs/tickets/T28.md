# T28: `t2c result` says how the old way was timed

[#77](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/77) · PR [#80](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/80) · in review

`t2c result` now has to be told where the old way's time came from, so the Side-by-Side Trial's page can't claim a stopwatch that never ran. A time from memory makes Time Saved an estimate, and the page says so.

## Spec

The page said "timed by that marketer's stopwatch" whatever had happened. In T12's trial the old way's time came from memory, and the copy in `docs/results/` had to be corrected by hand. From #38.

- **Done when:**
  - `t2c result` takes a required `--old-way-source stopwatch|memory`, and refuses to run without it or with any other value.
  - With `memory`, the page doesn't say the old way was timed by a stopwatch, says the time is from memory, and labels Time Saved as an estimate.
  - With `stopwatch`, the page still says what it says today.
  - The help text and `docs/side-by-side.md` match the new flag.
- **Decisions:**
  - **A required flag, not a default:** the human chose this, so the page never guesses. `film_result` takes it as a required keyword too, and refuses an unknown value itself.
  - **The stopwatch line wasn't the only claim.** Six things on the page said or implied it, and `memory` changes all of them:

    | On the `stopwatch` page | Why it's wrong for `memory` | On the `memory` page |
    |---|---|---|
    | `Time Saved:` | reads as a measurement | `Time Saved (estimate):`, and the same when the new way was slower |
    | `## How it was measured` | the old way wasn't measured | `## Where the numbers came from` |
    | `240 min of active work, timed by that marketer's stopwatch` | the claim itself. "Active work" is gone too: nobody recorded what the minutes held | `240 min, from memory, so Time Saved is an estimate, not a measurement` |
    | `60 min of active work, timed the same way` | "the same way" would now mean from memory, or that both were timed alike | `60 min of active work, as that marketer gave it` |
    | `Both started with ... and stopped with ...` | states as fact what a remembered time can't show | what the protocol asks, and that a time from memory can't show the old way kept to it |
    | `a check on the stopwatch, not the measure` | no stopwatch to check, and the Run Logs say nothing of the old way | a check on Trailer-to-Campaign's time only; nothing checks the old way's |

  - **The new way's source stays unknown on a `memory` page.** The flag is only about the old way, so the page doesn't say how the new way was timed. A `--new-way-source` wasn't asked for and isn't added. A `stopwatch` page still says "timed the same way" unchecked, because the ticket keeps that page as it is.
  - **`result.json` carries it too:** `old_way_source` and `time_saved_is_estimate`, in both modes, because its `time_saved_minutes` would otherwise read as a measurement. It's the one change a `stopwatch` run makes.
  - **`README.md` changes too,** though the ticket names only the help and `docs/side-by-side.md`: it gives the command, which would now be refused without the flag.
  - **The T12 records stay as they are.** `docs/tickets/T12.md` describes what the page did then, and `docs/results/t12-side-by-side.md` was already corrected by hand.

## Plan

The human approved the required flag, and that approval was this ticket's plan gate.

- **Tests first, in their own commit, at the human's request:** `tests/test_result.py` for the page and JSON, `tests/test_cli.py` for the flag, help and docs. Existing result tests now pass `stopwatch`.
- **Files:** `src/trailer_to_campaign/result.py`, `src/trailer_to_campaign/cli.py`, `docs/side-by-side.md`, `README.md`.
- **No agent, prompt or model changed**, so no Eval Set run and no effect on cost per Run. `agents_hash()` is `d2681cbd...` before and after.
- **Changed during Build:** `cli.py` keeps its own copy of the two values, because importing `result.py` at the top would load the pipeline for every command. A test holds the copies equal.

## Tests

28 new cases, all failing before the fix: 17 in `tests/test_result.py`, 11 in `tests/test_cli.py`. They cover both sides: a `memory` page must drop each claim above and keep what isn't about time, a `stopwatch` page must match the text taken from `main`, and a missing or unknown value is refused with nothing written.

The first draft of the refusal test passed for two of its values before the flag existed: argparse refuses an unknown flag with the same exit code and names it in the message. So the test now requires argparse's actual reason, "required" or "invalid choice".

Full suite: 1133 passed, 1 deselected, up from 1105 by the 28 new cases. No new test starts a subprocess.
