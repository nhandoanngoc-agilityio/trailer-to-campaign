# T13: Demo kit for the company talk

[#13](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/13) · PR [#66](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/66) · merged

The demo kit for the talk: a script for a live Slack Run where the Checker catches a planted spoiler, a backup recording, and the side-by-side slide from T12. The recording shows a Checker flag on a stray note, not the planted spoiler, as the Evidence explains.

## Spec

A scripted live Slack run on a trailer with a planted spoiler the Checker catches, a recorded backup of the same run, and the side-by-side slide from T12.

- **Done when:** the live run and the backup recording both show the Checker catch, and the slide is ready.
- **Checks:**
  - **The live run:** in the test channel, following the script, the thread shows "⚠️ The Checker flagged the edit" and the reason arrives privately. In that Run's Run Log, the `post_checked` event for the edit has `verdict: "reject"` and `spoiler_ids: ["ending-capture"]`, and its `approval` event doesn't approve it.
  - **The backup recording:** a recording of the same script exists outside git. A person watches it and notes the time at which the flag appears.
  - **The slide:** every number on it matches `docs/results/t12-side-by-side.md`, it calls Time Saved an estimate, and it leaves out the Film's title unless the Film has launched.
- **Decisions:**
  - **How the catch is shown:** the human chose a scripted edit. On stage, the Marketer edits a Social Post to add the ending, and the Checker's re-check flags it. In past Runs the Copywriter fell into this spoiler by itself in only about half of them, and the thread then only reads "passed after 1 retries".
  - **The slide:** the human chose a one-slide deck.
  - **The Film:** Agent 327, whose trailer says the listed ending out loud. It's public, its spoiler is public, and it isn't the T12 Film, whose Spoiler List is real unreleased plot.
  - **Who's the Marketer on stage:** the human. `T2C_MARKETERS` must hold their id again (T12 run sheet, Step 8).
  - **The evidence:** the human decided not to make a second Run, and to close T13 on the one below. It shows a Checker flag, not the planted spoiler, so the first check above didn't pass and the Done-when's catch is only partly shown.
  - **The licence:** Agent 327's film file is CC-BY-ND, not plain CC-BY as the repo's "open movie" note suggested, and its post's comments rule out advertising and remixing. So the demo stays inside the company talk, its posts aren't published, and the trailer isn't edited. `docs/demo.md` says so.

## Plan

The plan was approved before Build. No agent, prompt or app code changes, so no failing tests come first. The checks are a paid measurement and the live run.

- `docs/demo.md`: the script, the checklist and what to do if it goes wrong.
- A local, gitignored demo Film, `films/demo-agent-327/`, so a demo Run reads a local trailer. Adding `trailer_file` to the tracked sample Film would refuse the README's command on a fresh clone, because the footage isn't in git.
- The slide: a private one-slide deck.

## Evidence

- **The planted sentence, before relying on it:** the real `recheck` from `real_stages`, through the Film Budget meter, on the sentence added to a real Facebook English post from Run `20261103T094741Z`. Caught 5 of 5, each naming `ending-capture`, for $0.0633 in all. The plan expected about $0.18.
- **The slide:** [T12 Side-by-Side Slide](https://claude.ai/artifact/4VXirN9AuqV35TWEyRXWwf), private. Its numbers match `docs/results/t12-side-by-side.md`, it calls Time Saved an estimate, and it names the Film only by genre.
- **The live run:** `20261104T035322Z`, completed for $0.4435, inside the $2.00 Film Budget, reading the local trailer. It shows a Checker flag on a Marketer's edit, but **not the planted spoiler**. The text pasted into the post was the script's spoken line, not the planted sentence, because the two sat side by side in the script's table. The Run Log has `spoiler_ids: []` and `rules: ["other"]`. The private reason, as the human saw it: "The post ends with a stray note about the drafting process that isn't marketing copy." The post was rejected. The script now separates the two, and says a flag alone isn't the catch.
- **A real spoiler catch in the same Run:** the Checker rejected the Copywriter's TikTok English post, naming `ending-capture` over "Famous last words at the barbershop", and a retry fixed it. That spoiler wasn't planted, and the thread only shows "after 1 retries".
- **The backup recording:** the human recorded this same Run, with the flag at 5:30, which matches the Run Log's 5 min 29 s. It shows the same brand flag. Claude hasn't seen the video, and it's kept outside git.
- **Not shown:** the planted sentence caught in live Slack and on the recording. It's been caught only through the real `recheck` outside Slack, 5 of 5 above, and a shorter version was caught live in the 1 Nov rehearsal. A second Run wasn't made: the human decided on 2026-11-04 that this Run is enough. See #38.
