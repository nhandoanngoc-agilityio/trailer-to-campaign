## Spec

A scripted live Slack run on a trailer with a planted spoiler the Checker catches, a recorded backup of the same run, and the side-by-side slide from T12.

- **Done when:** the live run and the backup recording both show the Checker catch, and the slide is ready.
- **Checks:**
  - **The live run:** in the test channel, following the script, the thread shows "⚠️ The Checker flagged the edit" and the reason arrives privately. In that Run's Run Log, the `post_checked` event for the edit has `verdict: "reject"` and `spoiler_ids: ["ending-capture"]`, and its `approval` event doesn't approve it.
  - **The backup recording:** a recording of the same script exists outside git. A person watches it and notes the time at which the flag appears.
  - **The slide:** every number on it matches `docs/results/t12-side-by-side.md`, it calls Time Saved an estimate, and it leaves out the Film's title unless the Film has launched.
- **Decisions:**
  - **How the catch is shown:** the human chose a scripted edit. On stage, the Marketer edits a Social Post to add the ending, and the Checker's re-check flags it. In past Runs the Copywriter fell into this spoiler by itself in only about half of them, and the thread then only reads "passed after 1 retries".
  - **The slide:** the human chose a one-slide deck.
  - **The Film:** Agent 327, whose trailer says the listed ending out loud. It's public, its spoiler is public, and it isn't the T12 Film, whose Spoiler List is real unreleased plot.
  - **Who's the Marketer on stage:** the human. `T2C_MARKETERS` must hold their id again (T12 run sheet, Step 8).
  - **The licence:** Agent 327's film file is CC-BY-ND, not plain CC-BY as the repo's "open movie" note suggested, and its post's comments rule out advertising and remixing. So the demo stays inside the company talk, its posts aren't published, and the trailer isn't edited. `docs/demo.md` says so.

## Plan

The plan was approved before Build. No agent, prompt or app code changes, so no failing tests come first. The checks are a paid measurement and the live run.

- `docs/demo.md`: the script, the checklist and what to do if it goes wrong.
- A local, gitignored demo Film, `films/demo-agent-327/`, so a demo Run reads a local trailer. Adding `trailer_file` to the tracked sample Film would refuse the README's command on a fresh clone, because the footage isn't in git.
- The slide: a private one-slide deck.
