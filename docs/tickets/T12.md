# T12: Real Film, side by side

[#12](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/issues/12) · PR [#43](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/43) (`t2c result`, the protocol), [#44](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/44) (the trial's decisions), and the result PR [#65](https://github.com/nhandoanngoc-agilityio/trailer-to-campaign/pull/65), in review

A Side-by-Side Trial on one real Film gave the project its first Time Saved, Approval Rate and cost per Film from a real launch: `docs/results/t12-side-by-side.md`. Time Saved is indicative only, because the old way wasn't timed as the protocol asks.

## Spec

Pick one upcoming Film. One marketer prepares its posts the old way while another uses Trailer-to-Campaign. Record both times, Approval Rate and cost.

- **Done when:** there is a one-page result with Time Saved, Approval Rate and cost per Film for that real launch. Cost per Film is the sum of all the Film's Run Logs, re-runs included, since the Film Budget caps each Run, not the Film.
- **Decisions:**
  - **The Film:** the human's own upcoming short. It meets `docs/side-by-side.md` and isn't in the Eval Set, though it has no dialogue: its catalog language is English, and the protocol's preference for dialogue only applies when two Films qualify. The result page says this makes it an easy case. Its title stays out of the repo until it has launched.
  - **The marketers:** two people. A one-person run was considered and dropped. The human built the tool, so they took the old-way side and the result says so.
  - **The Approval Rate:** from the Run whose Campaign was used.
  - **The measure:** stopwatch on both sides, with Run Log time beside it as a check.
  - **The trailer:** the 40-second cut, read from a local copy (T23). Both 90-second versions stay out of any model's reach (ADR 0005).
  - **The cost:** the run sheet keeps the earlier Watcher-only test ($0.1136) out of Cost per Film, with its Run Log outside `runs/`. That stretches the Done-when's "all the Film's Run Logs", so the result page shows $0.3638 beside $0.2502.

## Plan

`t2c result` and the protocol came first, in #43, then the trial's decisions and glossary terms in #44. The trial then waited on T18, T21, T22 and T23, because a real rehearsal and the T10 live run showed problems a one-off trial couldn't afford.

**Changed from the plan on the day:**
- The trial moved up from 2026-11-06 to 2026-11-03.
- The two sides didn't start together. A did the old way that afternoon, and B's Run started at 23:47.
- A's 40 minutes is from memory, not a stopwatch.

The result page states all three. `result.py`'s generated page, `runs/<film>/result.md`, says both sides were timed by stopwatch and started with the same inputs, whatever happened. So the copy in `docs/results/` is written by hand, and the generated page isn't copied as it stands.

## Tests

No code changes in the result PR. #43 took the suite to 695 tests, and it was 985 when this PR branched. The T12 tests prove:

- Cost per Film adds up every launch Run, including failed and killed ones, and leaves out Eval Set and dummy Runs.
- The Run that was used is the last to finish that gave a Campaign, or the one named with `--run`.
- The page holds no post, Key Moment, spoiler or local path.
- A malformed Run Log is refused with a message, and a slower new way is said plainly.
