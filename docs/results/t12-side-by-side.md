## Read these numbers with this in mind

This trial did not fully follow `docs/side-by-side.md`:

- **The two sides did not start together.** Marketer A did the old way on the afternoon of 2026-11-03. Marketer B's Run started at 23:47 that night.
- **A's 40 minutes is from memory.** It wasn't timed with a stopwatch and written down on stopping, so Time Saved is an estimate, not a measurement. B's 5 minutes was timed with a stopwatch, paused while the agents ran.
- **A isn't a typical old-way marketer.** A built the tool, made the Film, and wrote its facts and Spoiler List. The protocol puts whoever set up the tool on the old-way side for this reason. A knew the Film far better than a marketer normally would, which may make the old way look faster than it is.
- **What A used:** the trailer, A's own writing and ChatGPT for the Vietnamese.
- **One Film, one Run.** This shows the tool working on a real launch. It doesn't show an average.

A's work came before B's Run, so A hadn't seen the tool's output for this Film while writing.
